# Bafliex Cakes Arena Website

Production domain: https://bafliexcakes.co.ke/

## Deploy on Netlify from GitHub
- Build command: `npm run build`
- Publish directory: `dist`
- Connect the GitHub repository to Netlify. Netlify will build automatically after each push to `main`.

## V10 updates
- Wedding estimator supports sample packages or fully custom cake quantities.
- Wedding flavours allow up to 4 selections from the Bafliex flavour list.
- Custom cake builder supports custom shape, custom sizes from 3kg–10kg in 0.5kg steps, special notes and multiple inspiration photos.
- Added printable A4 wedding estimate and natural-height cake-order print layout.
- Added browser PDF generation with Share PDF / WhatsApp using the device share sheet where supported.
- Added real Bafliex cake gallery images supplied for the site.
- Expanded Cake Training content using the supplied training poster: 1 week Ksh 9,500; 2 weeks Ksh 17,500; 3 weeks Ksh 35,000; 8 weeks Ksh 60,000; 4–5 practical hours daily; ingredients/tools/equipment provided; full-course apron/notebook/pen; take-home baked goods; certificate.

## V11 inspiration catalogue
The home page now includes a searchable, filterable Bafliex inspiration gallery with 32 curated real-cake entries. Customers can choose a category or more specific type (for example Girls Cartoon Cakes, Teen Boys Cakes, Gentlemen Cakes, Church Cakes, Graduation Cakes, Wedding Cakes, Ruracio Cakes and Baby Shower), search by theme/occasion, and tap **Use as Inspo** to carry that design into the Custom Cake Builder. The selected catalogue inspo is included in the order review, PDF and WhatsApp summary.
